# AT Wedding Planner — Krishna Groups

Complete end-to-end Multi-Wedding Planning Web Application with:
- Multi-Wedding Workspaces & 3-Tier RBAC (Super Admin, Sub-Admin, Member)
- User Display Pictures (Avatars) & Module-Level Permissions Matrix
- Smart Guest CSV Import/Re-Import (Upsert without duplicates) & Export
- Invites & Media Studio (Cards, Posters, Videos, Hyperlinks & WhatsApp Share)
- Pure Catering & Menu List
- Expense & Payment Tracker with Live Multi-Photo Receipt Camera & Lightbox Viewer
- Family/Team Task Assignment & Workload Balancing
- Admin Master Activity Audit Trail & Real-Time Supabase Cloud Sync

## Quick Start
```bash
npm install
npm run dev
```
See `SUPABASE_SETUP.md` for cloud sync and GitHub Pages deployment instructions.
